# claude not

Projeto sincronizado via Git para trabalhar de qualquer computador.

## Como continuar em outro PC

```bash
git clone <url-do-repositorio>
cd "claude not"
```

Depois, para pegar as últimas alterações:

```bash
git pull
```

E para enviar suas alterações:

```bash
git add .
git commit -m "descrição da mudança"
git push
```
